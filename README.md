# Hi, I'm Tobey 👋

Web 与 AI 学习者，正在把写代码、做项目和长期写作变成稳定的习惯。

我在 [Aliseblu](https://aliseblu.cn) 记录软件、工具、技术实践与持续学习，也希望让零散的想法慢慢长成可以复用的体系。

- 🌌 持续迭代个人博客 Aliseblu 的内容系统、搜索体验与交互背景
- 🧭 学习 Web 工程、TypeScript、Go 与 AI 应用开发
- ✍️ 把解决问题的过程整理成文章、随记和项目复盘
